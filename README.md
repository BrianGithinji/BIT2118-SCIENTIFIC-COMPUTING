# BIT 2118 – Scientific Computing  
## Complete Individual Submission Package

### Folder structure

```
BIT2118_Full_Solution/
├── README.md
├── docs/
│   └── Full_Analysis_Report.md   ← Requirements B, C, D for every task
├── original_codes/               ← Exact codes from the handout (Tasks 2–20)
└── modified_codes/               ← One related real-world variant per task (Requirement E)
```

### How to use

1. Run any original program:
   ```bash
   python original_codes/Task_02_numpy_arrays.py
   ```

2. Run the corresponding modified version:
   ```bash
   python modified_codes/Task_02_modified.py
   ```

3. Read the full written analysis (inputs, parameter change, output meaning, graph interpretation) in:
   ```
   docs/Full_Analysis_Report.md
   ```
